Le niveau technologique du manuel décrit des machines complètes : chaque instruction y est écrite. Ces machines ont souvent des milliers d’instructions, et personne ne les vérifierait à la main. On les a donc programmées. Les programmes sont rassemblés ici ; il n’est pas nécessaire de savoir programmer pour les lancer, il suffit de suivre les instructions d’installation.

Télécharger les programmes (programmes.zip)

Installer et lancer

Les programmes n’ont besoin que de Python 3 (version 3.8 ou plus récente), sans aucune bibliothèque supplémentaire.

  1. Installer Python. Sous Linux et macOS, il est en général déjà présent : taper python3 --version dans un terminal. Sinon, ou sous Windows, le télécharger sur python.org (sous Windows, cocher « Add Python to PATH » pendant l’installation).
  2. Décompresser programmes.zip : on obtient un dossier programmes.
  3. Ouvrir un terminal dans ce dossier (sous Windows : clic droit dans le dossier, « Ouvrir dans le terminal » ; sous macOS : clic droit, « Nouveau terminal au dossier »).
  4. Lancer la vérification : python3 tests.py (sous Windows : py tests.py). Au bout d’une dizaine de secondes, le programme affiche « Tout est conforme. »

Chaque fichier lancé sans argument (python3 compilateur.py) affiche son mode d’emploi.

Les fichiers

Chaque programme correspond à un chapitre. Les trois premiers suffisent pour voir une machine de Turing calculer et pour fabriquer automatiquement une machine à partir d’une formule.
FichierCe qu’il faitChapitre
machines.pySimulateur de machines de Turing à quadruplets. Lit les fichiers .tm (un quadruplet par ligne) et affiche, si on le demande, chaque étape du calcul.Machines de Turing
exemples/*.tmLes machines du chapitre 3 : addition, soustractions, constantes, projections, multiplication, signe, égalité.Exemples
recursives.pyLes fonctions récursives : les six briques $C$, $S$, $A$, $\sigma$, $\rho$, $\mu$, l’évaluation d’un terme, une bibliothèque (opérations, comparaisons, quotient, couples de Cantor…), et l’écriture commode par substitution générale.Fonctions récursives
compilateur.pyLe compilateur des fonctions récursives vers les machines de Turing : il écrit la machine complète, l’exécute, compare le résultat.Équivalence
turing_vers_recursif.pyLe sens réciproque : une machine de Turing devient un terme récursif avec une seule minimisation (forme normale de Kleene), vérifié pas à pas.Équivalence
lambda_calcul.pyRéducteur de λ-termes en ordre normal, entiers de Church, et compilateur des fonctions récursives vers le λ-calcul.λ-calcul, Équivalence
universelle.pyUne fonction universelle $U(e,x)$ écrite avec les six briques, puis, en la compilant, une machine de Turing universelle (environ 30 millions de quadruplets).Universalité
recursion.pyLe théorème s-m-n sur les machines de Turing ; le point fixe de Kleene ; un programme qui affiche son propre texte.s-m-n et récursion
arret.pyL’argument diagonal exécuté : quatre « décideurs de l’arrêt » candidats, et le programme qui met chacun en défaut.Indécidabilité
piles.pyAutomates à deux piles : la traduction d’une machine de Turing, les deux piles jouant les deux moitiés de la bande, vérifiée pas à pas.Autres modèles
compteurs.pyMachines à compteurs : la bande rangée dans deux nombres (en binaire pour les blancs et les barres), puis deux compteurs seulement grâce aux nombres premiers ; un interpréteur qui exécute des machines de 1027 pas.Autres modèles
post.pyLe problème de correspondance de Post : la liste de dominos d’une machine de Turing, la solution tirée de son calcul, et une recherche en largeur.Autres modèles
logique_post.pyDes dominos à la logique : un énoncé avec une relation et une fonction binaires, valide si et seulement si les dominos ont une solution (format TPTP pour les démonstrateurs automatiques).Logique et types
tests.pyVérifie toutes les affirmations précédentes.

Quelques commandes

python3 machines.py exemples/addition.tm 2 3 --trace
python3 recursives.py "rho[A(1,1), sigma[S, A(3,2)]]" 2 3
python3 compilateur.py mult 2 3 --sortie mult.tm
python3 machines.py mult.tm 2 3
python3 turing_vers_recursif.py exemples/soustraction_propre.tm 5 2
python3 lambda_calcul.py --compiler fact 3
python3 universelle.py
python3 universelle.py --machine
python3 recursion.py
python3 arret.py
python3 piles.py exemples/addition.tm 1 1 --trace
python3 compteurs.py exemples/addition.tm 2 1
python3 post.py
python3 logique_post.py

La syntaxe des termes est celle du chapitre Fonctions récursives : C(k,m) pour la constante $m^{(k)}$, S, A(k,i) pour $A^{(k)}_i$, sigma[g, h1, ..., hk], rho[g, h], mu[g] ; les lettres grecques σ, ρ, μ sont acceptées, ainsi que les noms de la bibliothèque (python3 recursives.py --liste).

Les autres programmes du manuel

Les programmes de vérification des chapitres plus avancés (castors affairés, complexité, Presburger, Kolmogorov, hasard quantique…) sont dans le dossier assets/code/ du site ; chacun se lance avec python3 fichier.py (ou se compile avec cc pour les fichiers en C) et vérifie ce qu’il affirme.
